What We Scanned

The 7 top MCP servers (by stars) plus the Anthropic skills repo were cloned and run through the Gardu static scanner. We apply Hexbane rule philosophy across families HB101–HB701: hidden content, injection, secrets, execution & exfiltration, MCP config, and tool manifest.

Limits: This is a pattern/structure scanner that reads text — it does not execute code or follow URLs. PASS = "nothing known found", not "safe". A clean scan means no known bad patterns were detected; it does not guarantee the code is secure.
